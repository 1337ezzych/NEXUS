# NEXUS — Telegram client starter

NEXUS is a SwiftUI starter for an iOS Telegram client with an original premium-inspired interface.

## Important status

This archive is a **source starter**, not a ready-to-install IPA. It does not include:
- a compiled TDLib binary / `TDLib.xcframework`;
- an Xcode project generated by Xcode;
- Telegram API credentials;
- a completed production messaging implementation.

The demo UI runs independently of TDLib. The `Telegram` folder contains an integration scaffold that must be connected to a matching TDLib build and tested.

## Requirements

- macOS with a compatible version of Xcode to build/sign an iOS app;
- iPhone simulator or a supported iPhone;
- Telegram API ID and API hash from https://my.telegram.org;
- TDLib built for iOS from https://github.com/tdlib/td.

Linux can be used to edit the source and manage Git, but a normal iOS app build/signing workflow requires Apple's toolchain. GitHub Actions macOS runners can be used for CI once a real `.xcodeproj` is added.

## Layout

- `Sources/NEXUS/` — SwiftUI demo application.
- `Sources/NEXUS/Telegram/` — TDLib integration scaffold.
- `Configuration/` — example configuration and bridging header.
- `.github/workflows/` — CI workflow template.
- `Documentation/` — setup and App Store notes.

## Quick start

1. Create a new iOS App project in Xcode named `NEXUS` (SwiftUI, Swift).
2. Add all `.swift` files from `Sources/NEXUS/` to the app target.
3. Set the deployment target to iOS 16 or later (adjust if you choose newer APIs).
4. Build and run. The app initially uses demo data.
5. To enable Telegram, build TDLib for iOS and follow `Documentation/TDLIB_SETUP.md`.
6. Add your API ID and API hash using a secure configuration mechanism. Never commit real credentials.
7. Replace the demo repository with the TDLib-backed service and test authorization, updates, media, notifications, and lifecycle carefully.
